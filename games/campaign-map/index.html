Help
  • Pan drag empty space, or right-drag anywhere
  • Zoom scroll or pinch
  • Select click a feature; drag it or its handles
  • Select several Cmd/Ctrl-drag a box, Cmd/Ctrl-click to add or remove
  • Add a point double-click a line
  • Delete removes the point if you last clicked a handle, the whole feature if you clicked its line
  • Measure Shift-drag; Enter keeps it as the current tool's shape (a trail with Select), Esc clears it
  • Change a line's type select it, then click Contour, Trail, River or Area (Esc deselects first if you want to draw instead)
  • Closed trail tick Closed in the Selected panel
  • Add a place on a line end right-click the end of a trail or river
  • Extend a line Shift-drag from a place pinned to its end
  • Join rivers end one on another, or drag its last handle onto it
  • Hidden features small ones hide as you zoom out; hover to reveal
  • Undo Cmd/Ctrl-Z
